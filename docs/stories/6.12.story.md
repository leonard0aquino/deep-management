## Story

Como liderança Comercial, quero que a etapa atualmente exibida como **Chamado aguardando assinatura** passe a se chamar **Contrato aguardando assinatura**, para usar a nomenclatura correta do processo comercial.

## Acceptance Criteria

1. O funil Comercial, a TV Comercial, o formulário de edição do painel e o cadastro de oportunidades exibem **Contrato aguardando assinatura**.
2. Tooltips e rótulos acessíveis usam a nova nomenclatura.
3. O identificador técnico `awaiting_signature`, a coluna `awaiting_signature_count` e os dados existentes são preservados; nenhuma migration é necessária.
4. Testes são atualizados e `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.
