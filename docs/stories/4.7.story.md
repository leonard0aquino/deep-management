## Story

Como administrador da AISphere, quero que as visões de Gestão, Relatório e Metas sejam restritas ao meu perfil, para que informações e controles executivos não sejam acessados por gerentes ou analistas.

## Acceptance Criteria

1. Os itens `Gestão`, `Relatório` e `Metas` aparecem na navegação somente para usuários com perfil `admin`.
2. Usuários `gerente` e `analista` que tentarem acessar `/analytics`, `/reports/executive` ou `/goals` diretamente são redirecionados para `/my-day` antes do carregamento dos dados da tela.
3. Usuários não autenticados são redirecionados para `/login`.
4. Administradores continuam acessando as três telas e podem editar as metas internas.
5. Testes automatizados cobrem a navegação por perfil e a autorização server-side.
6. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.

## Dev Notes

- Ocultar itens na interface não substitui autorização; as três páginas devem validar o perfil no servidor.
- O fallback seguro para perfil ausente ou não administrativo é `/my-day`.
- O middleware e a guarda devem manter o redirecionamento de sessões ausentes para `/login`.
