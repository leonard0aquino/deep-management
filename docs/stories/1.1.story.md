# Story 1.1 — Redesign do Cockpit Executivo

## Status

Done

## Story

Como gestor de relacionamento, quero que o Cockpit Executivo adote a hierarquia visual e a densidade informacional da referência fornecida, para compreender indicadores, tendências e pontos de atenção com menos esforço, sem perder as funcionalidades existentes.

## Acceptance Criteria

1. O shell desktop apresenta sidebar fixa clara, item ativo escuro, identificação do produto e perfil do usuário no rodapé, seguindo a referência visual.
2. O topo do conteúdo apresenta título, data contextual e ações existentes em uma barra horizontal compacta.
3. Os principais indicadores aparecem em uma faixa de cards compactos, com rótulo, valor, ícone e tendência/contexto.
4. O conteúdo principal usa uma grade responsiva de duas colunas em desktop e uma coluna em telas menores.
5. Os painéis existentes (tendência de score, distribuição de saúde, briefing, mapa e atividade) continuam funcionais, mas adotam bordas sutis, raios menores, tipografia compacta e maior densidade visual.
6. Não há alteração de schema, regras de negócio, autenticação, rotas ou operações existentes.
7. A interface mantém contraste legível, foco visível, semântica de botões/links e comportamento responsivo.
8. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` são executados; scripts ausentes são registrados no resultado.
