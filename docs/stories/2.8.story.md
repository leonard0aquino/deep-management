## Story

Como usuário da visão 360° da Carteira, quero retirar os blocos operacionais inferiores do detalhe do cliente, para exibir somente as informações relevantes ao uso atual.

## Acceptance Criteria

1. O detalhe `/accounts/[id]` não renderiza **Cadências e playbooks**.
2. O detalhe não renderiza **Pendências** nem **Próximos Passos**.
3. O detalhe não renderiza **Arquivos**.
4. Cálculos e imports usados exclusivamente pelos blocos removidos deixam de ser executados nessa página.
5. Os componentes e serviços de domínio são preservados para possível reutilização; somente a composição da página é alterada.
6. Os blocos remanescentes aparecem nesta ordem: cabeçalho, Timeline, Qualidade dos dados, briefing, produtos e pessoas.
7. O contrato estrutural confirma a sequência completa do critério 6 e a ausência das três áreas removidas.
8. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.
