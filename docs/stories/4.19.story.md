## Story

Como responsável pelo produto, quero deixar as telas de Metas e Relatório Executivo indisponíveis para todos os usuários e remover seus botões de navegação, para que funcionalidades temporariamente fora de uso não sejam acessadas direta ou indiretamente.

## Contexto

- As telas foram criadas nas Stories 4.3 e 4.4 e posteriormente liberadas a perfis executivos.
- A desativação é reversível: componentes, serviços e persistência existentes são preservados.
- A indisponibilidade vale para todos os papéis e áreas, inclusive `admin` e `executivo`.

## Acceptance Criteria

1. Os itens **Relatório** e **Metas** não aparecem na navegação principal para nenhum papel ou área de negócio.
2. O acesso direto a `/reports/executive`, incluindo query strings, encerra em `notFound()` antes de autenticação, consultas ou agregações do relatório.
3. O acesso direto a `/goals` encerra em `notFound()` antes de autenticação, consultas ou agregações de metas.
4. A desativação também vale para `admin` e `executivo`; não existe exceção de perfil.
5. Gestão, Cockpit Executivo, Configurações e as demais áreas mantêm a governança e navegação atuais.
6. Componentes, serviços, testes de domínio, tabela `internal_goals` e políticas existentes não são removidos, permitindo reativação futura sem reconstrução da funcionalidade.
7. Testes verificam ausência dos dois links para admin e executivo, indisponibilidade das duas rotas e preservação dos demais itens de navegação.
8. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.

## Dev Notes

- A navegação é definida em `NAV_ITEMS` dentro de `packages/web/src/components/layout/app-sidebar.tsx`; remover os itens evita que qualquer papel receba os botões. [Source: `packages/web/src/components/layout/app-sidebar.tsx#NAV_ITEMS`]
- As rotas atuais carregam dados antes de renderizar. A chamada incondicional a `notFound()` deve ser o primeiro e único comportamento dos entrypoints desativados. [Source: `packages/web/src/app/(app)/goals/page.tsx`; `packages/web/src/app/(app)/reports/executive/page.tsx`]
- O bloqueio não altera capabilities porque outras telas executivas permanecem disponíveis.
- Não há alteração de schema, RLS, API ou componentes de domínio.
