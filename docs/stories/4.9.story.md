## Story

Como liderança da AISphere, quero impedir o registro acidental de interações em datas futuras, para que Timeline e Health Score reflitam o relacionamento real com clientes e produtos.

## Acceptance Criteria

1. A interação do Sigma registrada incorretamente em 28/07/2029 é corrigida para 28/07/2026 sem alterar seu conteúdo.
2. O formulário de interação não permite selecionar ou salvar uma data posterior ao dia atual da AISphere.
3. A API interna rejeita interações futuras com erro de validação.
4. A importação estruturada marca interações futuras como inválidas.
5. O banco rejeita inserções e alterações que deixem a data da interação posterior à data civil de criação em São Paulo.
6. Testes automatizados cobrem formulário, API, importação e migração.
7. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.
