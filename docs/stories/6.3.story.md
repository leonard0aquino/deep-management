## Story

Como liderança Comercial, quero uma visão separada da operação de vendas, para gerir atividade, funil e agenda sem misturar indicadores de Customer Success.

## Acceptance Criteria

1. Existe rota `/commercial` e item Comercial na navegação para usuários autorizados.
2. O dashboard exibe recência de nova reunião, NDA/POC, proposta e venda ganha usando dados estruturados.
3. O funil exibe volume, valor e conversão por etapa sem inferência de texto livre.
4. A agenda nativa mostra próximos passos com data e hora e destaca itens vencidos.
5. Filtros por período, responsável, etapa, empresa e produto atualizam todos os blocos de forma coerente.
6. Usuários comerciais enxergam sua estrutura autorizada; Admin e Executivo podem ver toda a área.
7. Interações exibidas são somente as de origem Comercial.
8. O dashboard oferece criação rápida de interação e oportunidade.
9. Estados vazio, carregando e erro são claros e não fabricam métricas.
10. Há botão para abrir o Modo TV Comercial.
11. Testes cobrem métricas, filtros, escopo e navegação.
12. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` e `git diff --check` passam.
