# Story 1.8 — Base de Testes Automatizados do Cockpit

## Status

Done

## Story

Como equipe responsável pelo Cockpit, quero uma suíte automatizada para as regras e fluxos críticos já implementados, para detectar regressões antes de publicar novas evoluções.

## Acceptance Criteria

1. O pacote web possui test runner TypeScript compatível com Next.js e scripts `test` e `test:watch`.
2. `npm test` executa de forma determinística e encerra com código diferente de zero em falhas.
3. Regras de ações prioritárias cobrem criticidade, alerta, aging, ordenação, responsável e chave estável.
4. Filtros cobrem preservação/remoção de parâmetros e limpeza do recorte.
5. Visões salvas cobrem seleção de chaves permitidas e escaping de CSV.
6. O motor de notificações cobre usuário ausente, preferências, deduplicação e payload por severidade.
7. Auto-refresh cobre pausa em aba oculta, retomada e atualização manual sem ticks acumulados.
8. A migration corretiva de notificações possui teste estrutural para triggers de auditoria e rollback.
9. Testes não dependem de rede, credenciais reais ou banco de produção.
10. `npm run lint`, `npx tsc --noEmit`, `npm test` e `npm run build` passam.
