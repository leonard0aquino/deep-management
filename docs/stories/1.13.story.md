# Story 1.13 — Datas Locais na Agenda

## Status

Done

## Story

Como usuário da agenda, quero que atividades realizadas hoje sejam agrupadas como “Hoje”, para confiar na organização cronológica exibida.

## Acceptance Criteria

1. Datas no formato `YYYY-MM-DD` são interpretadas como datas locais, sem conversão implícita para UTC.
2. Uma atividade cuja data coincide com o dia local atual aparece no grupo “Hoje”.
3. Uma atividade do dia local anterior aparece no grupo “Ontem”.
4. Demais datas preservam a apresentação extensa em português.
5. O dado persistido no Supabase não é alterado.
6. Há testes cobrindo hoje, ontem e uma data anterior.
7. Lint, TypeScript, testes e build passam.
